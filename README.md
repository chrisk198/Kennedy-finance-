# Kennedy Pro 1.0

Upload all three files to the root of the existing GitHub repository:

- index.html
- manifest.json
- sw.js

Replace the old index.html.

## Included

- Detailed account profiles
- Account numbers, sort codes, references, APR, Direct Debit dates and notes
- Record debt payments
- Monthly bills, paid/unpaid status and totals
- Bank CSV statement import and bill matching
- House-deposit and emergency-fund goals
- Journey milestones
- Passcode lock
- Backup export and restore
- Migration from Kennedy Finance V5 local data where available
- Installable PWA support

## Important

This release does not make a live connection to a bank. A live Open Banking connection needs:
- a regulated/authorised Open Banking provider,
- a secure backend,
- encrypted token storage,
- a privacy policy and operational controls.

Do not put bank login details into the app.
